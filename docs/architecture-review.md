# gergram architecture review

The review covers all 81 work items in the [feature audit](ayugram-feature-audit.md). It records the native owner, source coverage, proposed implementation and acceptance evidence for each item. The [implementation plan](development-plan.md) records what has landed and what has run. The [media delivery design](media-delivery.md) expands C33 with the pinned transport, cache behavior and controlled performance measurements.

## Shared implementation decisions

- Keep user interface actions in the owning native package. Reuse AppKit and TGUIKit navigation, selection, accessibility and localization. Connect account operations through existing hooks and the active account context.
- Keep installation-wide display preferences in typed local settings. Store chat and account data in the account Postbox with explicit migration, observation and teardown. Preserve message identity, original payloads and server synchronization when applying local display changes.
- Keep capability decisions next to the native operation. Revalidate the account, chat and permissions at an asynchronous send, delete, export or external provider boundary.
- Run independent terminal fixtures against production code, then package and workspace tests against the exact pinned dependencies. Use disposable accounts and synthetic data for transport, capture and connected-service evidence. Record source coverage, package evidence and integrated coverage separately.
